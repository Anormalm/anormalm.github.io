Input contract

A small, explicit schema.

Each record requires a unique id, a task, ground_truth, original, neutral and semantic. Predictions must already be parsed: yes/no, a nonnegative integer for shortest path, or unclear. Ground truth cannot be unclear.

Task identifiers: connectivity, shortest_path, triangle_detection, common_neighbor.

Download example JSON →

Denominators are explicit

Accuracy uses all uploaded queries. Consistency excludes pairs containing unclear. CFM includes every initially correct query; an unclear semantic answer counts as a failure. Empty denominators display —.

For the complete protocol

This tool audits complete parsed triples. It does not infer answers, parse raw model prose, or compute format/order/distractor metrics. Use the released Python auditor for native results_*.json files, bootstrap intervals and the full diagnostics.
