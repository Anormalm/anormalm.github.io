GroundLM Hard v1 / Methodology

Test the graph.
Then test the representation.

A frozen, exact-answer benchmark for graph reasoning and structural invariance. One graph is the unit of evidence; its eight prompt variants are related observations.

01 / Generate120 independent graphs6 tasks × 2 sizes × 10 seeds
02 / Transform8 prompt conditionsSame target answer in every condition
03 / Query960 requests per modelFrozen prompts · no tools · 16,384-token cap
04 / AuditAccuracy + invarianceExact certificates · paired metrics · graph-level intervals

What the questions measure

TaskTarget answer
Weighted shortest pathMinimum total edge weight between two nodes.
Shortest-path countNumber of distinct shortest paths.
Exact-walk countNumber of walks with an exact specified length.
Triangle countTotal number of distinct graph triangles.
Minimum cutMinimum cut capacity between two nodes.
Constrained reachabilityWhether a path exists after excluding specified nodes (0 or 1).

Graphs have 32 or 64 nodes, with ten fixed seeds per task and size. Reachability has five positive and five negative labels at each size. No graph was selected based on model performance.

Eight views of the same question

Original → identical repeat

Byte-identical input, queried again. Measures response variation without a text intervention.

Neutral → aligned → reversed names

Arbitrary identifiers, then degree-aligned and degree-reversed meaningful names. Node meanings are explicitly declared irrelevant.

JSON format → shuffled order

Reserialize the graph or reorder its presentation while preserving its edges and query.

Disjoint distractor

Add an unrelated three-node path. The query answer is preserved; the enlarged graph is not isomorphic to the original.

Read each metric with its denominator

  • Accuracy: correct returned answers / returned responses. All-condition accuracy pools eight correlated prompts; original accuracy uses one per graph.
  • Agreement: same parsed answer on the original and transformed prompt / parseable pairs. Always inspect the eligible-pair count.
  • Renaming survival: correct degree-reversed answers / originally correct questions with a returned counterpart. Invalid and cutoff counterparts count as failures.
  • Cutoffs: token-limit responses without a correct final answer. Completed numeric mistakes and invalid completed responses are separate categories.
  • Matched semantic gap: neutral agreement minus reversed-name agreement on the same parseable triples, available in the downloadable metrics.

Model details show 95% Wilson intervals at the graph level. The full metrics also include 2,000 task/size-stratified bootstrap draws. An empty denominator is undefined, never zero or perfect.

Inference and collection

The reference run uses five pinned endpoint configurations, 16,384 maximum completion tokens, high reasoning effort when available (enabled otherwise), no tools, and provider-default sampling. Provider, precision, raw answers, token usage, charges, and launch journals are retained in the release.

Ling uses Novita with undisclosed precision after zero-charge rejections at its originally selected provider, before any successful generation. Other configurations are DeepSeek FP4, GLM FP8, MiniMax FP8, and Granite BF16. Different providers, tokenizers, and reasoning implementations mean this is a comparison of these endpoint configurations.

Only infrastructure failures were recovered. No wrong answer, invalid answer, or token cutoff was retried. Eight slots received a separately approved third attempt after two provider failures. All 4,800 slots have model responses; no API failures remain. Recorded cost and conservative uncertain-charge bounds total $17.44515, including $0.30615 in uncertain-cost bounds.

Scope and reproducibility

Six synthetic task families and two graph sizes do not establish natural-graph generalization. Degree-based names are not verified task roles, and relabeling changes tokenization. A high agreement score on a small parseable subset needs particular care. The unchanged-input repeat helps separate response variation from representation effects.

All 120 exact-answer certificates were independently verified. Frozen prompt and source hashes, immutable attempts, recovery approvals, scorer code, and the final audit are included. The earlier paper study and 21-model pilot are separate datasets and are not pooled into this leaderboard.
