How scoring works

Accuracy uses successful baseline requests. Consistency compares parsed answers and excludes unclear pairs. CFM is the share of initially correct answers that remain correct under semantic renaming; unclear semantic answers count as failures.

Each metric shows its denominator. Partial runs use available comparisons; HTTP failures are listed separately. Browser results are point estimates. Use the Python auditor for bootstrap intervals.

Service compatibility

The endpoint must accept a chat-completions request and return text in choices[0].message.content. Native Messages and Responses APIs require a compatible gateway. The service must allow this site's browser origin through CORS.

For local services, serve this website locally too. A remote HTTPS page may be blocked from calling an HTTP local server. Browser request behavior.
