01 / Environment

Install and verify.

The released code supports Python 3.10+. Start with its deterministic protocol tests.

git clone https://github.com/Anormalm/graph_evidence.git
cd graph_evidence/code
python -m venv .venv
# macOS / Linux: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
02 / Model inference

Run your configuration.

Set your provider key through the appropriate environment variable, such as OPENROUTER_API_KEY, on your own machine. You can also use the browser runner with your own key and a compatible endpoint.

python run_api_models.py --model deepseek/deepseek-v4-flash --endpoint openrouter --output-dir ../results

Use the runner's --help for available endpoints. Temperature is 0; reasoning settings vary by model. Preserve the model ID, configuration and raw generations with each run.

03 / Offline audit

Inspect the evidence.

python audit_results.py --results-dir ../results --output ../results/audit_summary.json

The auditor reports diagnostic estimates, bootstrap intervals, parse rates, per-task agreement, conditional correctness and candidate relabeling failures. No model inference is required for this step.

The corrected implementation changes query remapping, unclear-answer handling, order-sensitivity denominators and distractor verification. New results should be identified as corrected-protocol runs, rather than silently treated as exact reproductions of the published table.

Scope and interpretation

The study uses small synthetic graphs and four formats. Connectivity labels are all positive. The semantic relabeler assigns names in decreasing degree order; a role-incongruent intervention is not established by this generator. The shared prompt does not explicitly declare identifiers arbitrary. These factors matter when interpreting sensitivity.
