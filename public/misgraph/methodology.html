Metric definitions
  • Accuracy: correct returned answers / returned responses. All-condition accuracy pools eight correlated prompts; original accuracy uses one per graph.
  • Agreement: same parsed answer on the original and transformed prompt / parseable pairs. Eligible-pair counts are reported.
  • Renaming survival: correct degree-reversed answers / originally correct questions with a returned counterpart. Invalid and cutoff counterparts count as failures.
  • Cutoffs: token-limit responses without a correct final answer. Completed numeric mistakes and invalid completed responses are separate categories.
  • Matched semantic gap: neutral agreement minus reversed-name agreement on the same parseable triples, available in the downloadable metrics.

Model details show 95% Wilson intervals at the graph level. The full metrics also include 2,000 task/size-stratified bootstrap draws. Empty denominators are reported as undefined.

Inference settings and collection

The reference run uses five pinned endpoint configurations, 16,384 maximum completion tokens, high reasoning effort when available (enabled otherwise), no tools, and provider-default sampling. Provider, precision, raw answers, token usage, charges, and launch journals are retained in the release.

Ling uses Novita with undisclosed precision after zero-charge rejections at its originally selected provider, before any successful generation. Other configurations are DeepSeek FP4, GLM FP8, MiniMax FP8, and Granite BF16. Different providers, tokenizers, and reasoning implementations mean this is a comparison of these endpoint configurations.

Only infrastructure failures were recovered. No wrong answer, invalid answer, or token cutoff was retried. Eight slots received a separately approved third attempt after two provider failures. All 4,800 slots have model responses; no API failures remain. Recorded cost and conservative uncertain-charge bounds total $17.44515, including $0.30615 in uncertain-cost bounds.

Scope and reproducibility

This benchmark covers six synthetic tasks at two graph sizes. Node names follow degree, not task roles; renaming also changes tokenization. Agreement uses parseable pairs, whose counts are reported. Identical repeats measure baseline response variation. Results describe these tasks and endpoint configurations.

All 120 exact-answer certificates were independently verified. Frozen prompt and source hashes, immutable attempts, recovery approvals, scorer code, and the final audit are included. The earlier paper study and 21-model pilot are separate datasets and are not pooled into this leaderboard.
