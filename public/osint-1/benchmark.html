Open-web benchmark update

The agent starts with a brief and any images. It finds public sources and cites the evidence behind its findings.

The 120-case collection

There are 110 investigations and 10 controls across 117 case clusters. Every brief starts without source links. The collection covers entity resolution, geolocation, time and event reconstruction, provenance and claim checking.

What we checked

We reviewed all 120 briefs and ran OCR on the 103 unique starting images. The packet audit checked file names, image metadata, hashes and the boundary between solver files and curator notes. We removed two answer values from one brief. Some supplied maps and reports intentionally contain evidence the solver must interpret.

One live run

Qwen3.8-27B used eight model calls on one open-web timeline case. The report passed the format and citation-ID checks. The model recovered one milestone and left the requested comparison unfinished. Blind solves, independent evidence scoring and measured difficulty are pending.

How we compare runs

Models get the same brief, tool profile and comparison settings. We record what each tool delivered and review whether the cited records support the claims. A separate no-retrieval run helps identify cases the model can answer from memory.

Case walkthroughs and retained answers are in the private review library.
